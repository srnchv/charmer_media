# HANDOFF — Charmer Media лендинг

Передаточный документ для продолжения работы над лендингом медиа-направления
студии Charmer. Свёрстан из Figma-макета «BASE (Copy)».

## Что это и где лежит

- **Проект:** одностраничный лендинг «Дизайн медиа, которые читают».
- **Локально:** `charmer-media/` (эта папка).
- **Репозиторий:** https://github.com/srnchv/charmer_media (публичный).
  - `main` — исходники.
  - `gh-pages` — собранный `dist/` для GitHub Pages (деплой-ветка, историю
    не бережём, пушится force).
- **Живой сайт:** https://srnchv.github.io/charmer_media/
  (нужно, чтобы в Settings → Pages был включён Source = ветка `gh-pages`, root).

## Стек

- **Vite + React 18**, без лишних зависимостей.
- Скролл-анимация героя — свой хук на `requestAnimationFrame` + `position: sticky`.
- Всё содержимое (тексты, пути к ассетам) вынесено в `src/data.js`.

## Структура кода

- `src/main.jsx` — точка входа.
- `src/App.jsx` — весь каркас: боковые колонки (`LeftRail`, `RightRail`),
  секции контента (`Expertise`, `Method`, `Clients`, `Contact`, `Footer`) и
  оверлей hover-превью.
- `src/Hero.jsx` — первый экран со скролл-зумом (см. ниже).
- `src/data.js` — контент: `projects`, `opinion`, `principles`, `workScope`,
  `formats`, `clients`, `assets`.
- `src/styles.css` — все стили + CSS-переменные (цвета, шрифты, размеры колонок).
- `public/assets/` — 32 файла: иконки проектов, логотипы клиентов (SVG),
  фото обложки/футера, изображения карточек, превью проекта.

## Ключевые реализованные фичи

### 1. Скролл-зум героя (`src/Hero.jsx`)

Sticky-сцена высотой 260vh. Прогресс скролла (0..1) управляет раскадровкой:
обложка раскрывается из врезки (786px, скруглённая) на всю центральную колонку,
логотип charmer и заголовок уезжают вверх, в конце проявляется навигация
(«Наш опыт / Методология / Клиенты» с якорями). Темп зума сверялся с
промежуточными кадрами макета численно.

### 2. Фиксированные боковые колонки

- Левая («Хронология проектов») — скроллится независимо, `z-index: 30`.
- Правая («Мнения» + кнопка «Написать нам») — `z-index: 10`.
- Центр скроллится между ними. На ширине < 1100px колонки скрыты (`.rail { display:none }`).

### 3. Hover-превью проекта (Frame 18)

При наведении на карточку проекта, у которой в `data.js` задано поле `preview`:
- центр и правая колонка размываются (`backdrop-filter: blur(24px)` +
  белёсый тинт), остальные карточки приглушаются до 35%, наведённая яркая;
- поверх появляется резкое превью сайта, **прижатое к правому краю** (поля 16px,
  на всю высоту, без скруглений — как в макете).

Слои разведены по `z-index`: левая колонка (30) и превью (25) поверх
блюр-оверлея (20); центр и правая колонка под ним — поэтому размываются
именно они.

**Сейчас превью есть только у Inside The Games** (`preview-itg.jpg`) — это
единственный проект с превью в макете. Чтобы добавить превью другим проектам:
положить картинку в `public/assets/` и дописать в объект проекта в `data.js`
поле `preview: A('имя-файла')`. Код менять не нужно — эффект включится сам.

Эффект только для десктопа (на мобиле колонок нет). Тач-версии пока нет.

## Шрифты — ВАЖНО (пока стоят заглушки)

В макете используются платные шрифты, сейчас подключены Google-аналоги
(через CSS-переменные в `:root` в `styles.css` и `<link>` в `index.html`):

| В макете               | Временно стоит   | Переменная      |
| ---------------------- | ---------------- | --------------- |
| William Subhead LC     | Source Serif 4   | `--font-serif`  |
| ABC Monument Grotesk   | Inter            | `--font-sans`   |
| Even Mono              | PT Mono          | `--font-mono`   |

Чтобы поставить оригиналы: добавить `@font-face` и поменять значения трёх
переменных — вся типографика подтянется.

## Как запускать и деплоить

```bash
cd charmer-media
npm install
npm run dev        # http://localhost:5173
npm run build      # прод-сборка в dist/
```

**Деплой на GitHub Pages** (после `npm run build`):

```bash
git push                                    # сначала main
git worktree add -B gh-pages /tmp/ghp HEAD && \
  find /tmp/ghp -mindepth 1 -maxdepth 1 ! -name .git -exec rm -rf {} + && \
  cp -r dist/. /tmp/ghp/ && touch /tmp/ghp/.nojekyll && \
  git -C /tmp/ghp add -A && git -C /tmp/ghp commit -m "Deploy" && \
  git -C /tmp/ghp push --force-with-lease && git worktree remove /tmp/ghp
```

## GitHub-доступ (нюансы)

- `gh` CLI не установлен; операции — через `git` + токен из keychain.
- Токен для этого репо сохранён локально с `credential.useHttpPath=true`,
  поэтому обычный `git push` из папки работает и не задевает другие токены.
- У токена **нет** scope `workflow` — поэтому файлы в `.github/workflows/`
  пушить нельзя (из-за этого авто-деплой через GitHub Actions не настроен,
  деплоим руками через `gh-pages`, см. выше). Если добавить токену scope
  `workflow` — можно перейти на Actions и деплоить обычным `git push`.

## Известные баги, которые уже пофикшены

- **Искажение SVG-логотипов:** файлы из Figma сохранялись с
  `preserveAspectRatio="none"` и `width/height="100%"` → браузер рендерил их
  боксом 300×150 и растягивал. Пофикшено: во всех SVG проставлены `width/height`
  из `viewBox`, `preserveAspectRatio="none"` удалён. Если будешь докидывать
  новые SVG-логотипы из Figma — проверь у них эти атрибуты.
- Иконка «Смысловой 226» (`proj-smyslovaya.png`) пересобиралась отдельным
  экспортом ряда с кропом — в базовой выгрузке терялся текстовый слой «226».
